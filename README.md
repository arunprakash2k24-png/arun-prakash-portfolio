# Arun Prakash P — Portfolio

A responsive personal portfolio for an Electronics and Communication Engineering student.

## Included
- Responsive HTML/CSS/JavaScript portfolio
- Projects section
- Skills section
- Education section
- Certification gallery with certificate modal
- Dark/light mode
- Mobile navigation
- SEO metadata
- Real certificate images supplied by Arun
- GitHub Pages-ready static site

## Important before publishing
1. Add your real GitHub profile URL in `index.html` (replace the current generic GitHub links).
2. Add your resume as `assets/Arun_Prakash_P_Resume.pdf`.
3. Review project status/descriptions and update them to match your actual work.
4. Add GitHub repository links to individual projects when you have them.

## Run locally
Open `index.html` in a browser, or use any static web server.

## GitHub Pages
1. Create a public repository.
2. Upload all files/folders in this project.
3. In GitHub: Settings → Pages.
4. Select `Deploy from a branch`.
5. Choose `main` and `/root`.
6. Save and wait for GitHub to publish the site.

Your URL will usually be:
`https://YOUR_GITHUB_USERNAME.github.io/arun-prakash-portfolio/`

## Vercel
Import the GitHub repository into Vercel and deploy it as a static site.
